# Сравнение числа чтений по интервалам

Список интервалов и правила фильтрации зафиксировали до просмотра числа чтений. Для каждого интервала использовали число отнесённых к нему выравниваний. Среднюю глубину по основаниям учитывают отдельно.

Для приведения библиотек к сопоставимому масштабу использовали один набор интервалов. На другом, непересекающемся наборе оценивали разброс отношений после нормализации. Нулевые значения в оцениваемой библиотеке сохраняли. Для пяти частей изучаемого интервала отдельно учитывали, сколько целей выдержало порог в обеих сравнительных библиотеках.

На искусственных примерах проверили нормализацию при разном размере библиотек, сохранение нулей и воспроизведение известного двукратного различия. Такой профиль описывает относительные количества чтений. Для определения абсолютного числа копий нужна отдельная проверка метода.

## Повторный подсчёт по выравниваниям

В центре каждого выбранного интервала задали окно одинаковой длины. Для повторного подсчёта использовали новые контрольные окна и сгруппировали их по содержанию гуанина и цитозина. Фрагменты пересчитали при двух порогах качества картирования, а соседние участки проверили отдельно. При сравнении нескольких позиций учитывали, соединяет ли их один физический фрагмент. Совпадение нескольких подсчётов на исходной библиотеке показывает воспроизводимость измерения. Для лабораторного подтверждения требуется независимый анализ.

При проверке выбранных позиций во всех выравниваниях применили одинаковые фильтры качества. Согласующиеся чтения одной пары учитывали один раз. Для каждого набора фильтров сверили общее число фрагментов, направление первого чтения и число различных положений пар.
