# Проверка коротких вставок и делеций по чтениям

Для каждого выбранного изменения сравнивали последовательность чтения с референсным и альтернативным вариантами, включая фланги по обе стороны. Для соседних изменений проверяли также их возможные сочетания на одном фрагменте. Это позволяет учитывать случаи, когда выравниватель обозначает одну и ту же последовательность разными операциями.

Перекрывающиеся концы одной пары учитывали один раз. Фрагменты с другой, частично прочитанной или неоднозначной последовательностью выделяли отдельно. Подсчёт проверили на искусственных примерах со вставкой, делецией, повтором и соседними изменениями.
