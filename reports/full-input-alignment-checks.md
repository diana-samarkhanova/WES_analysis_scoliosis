# Проверка полных выравниваний на GRCh38

Проверены полные выравнивания пяти входных наборов парных чтений. Всего учтены 153 178 103 пары и 306 356 206 первичных записей. Из них 306 336 839 сопоставлены с референсом, 19 367 остались несопоставленными. Дополнительные и вторичные выравнивания исключены из этого знаменателя.

Для очередного завершённого выравнивания использованы BWA-MEM 0.7.19-r1273 и SAMtools 1.25. После координатной сортировки проверили индекс и полностью перечитали записи BAM. Сверка с исходными чтениями учитывает повторяющиеся записи с сохранением числа их появлений. Дополнительно проверены сохранённые отчёты выполнения и их контрольные суммы.

Эти показатели описывают сохранность входных данных и долю выровненных чтений. Для оценки полноты покрытия экзонов требуются отдельные измерения глубины. Перед дальнейшей обработкой предусмотрена повторная сверка контрольных сумм выравнивания и индекса. Полный анализ продолжается.
