# Проверка полных выравниваний на GRCh38

Проверены полные выравнивания четырёх входных наборов парных чтений. Всего учтена 124 731 601 пара и 249 463 202 первичные записи. Из них 249 447 493 сопоставлены с референсом, 15 709 остались несопоставленными. Дополнительные и вторичные выравнивания исключены из этого знаменателя.

После сортировки проверяли индекс и последовательно перечитывали записи BAM. Сверка с исходными чтениями учитывает повторяющиеся записи с сохранением числа их появлений. Эти показатели описывают сохранность входных данных и долю выровненных чтений. Для оценки полноты покрытия экзонов требуются отдельные измерения глубины.
