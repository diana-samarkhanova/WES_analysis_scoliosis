# Проверка глубины чтения по кодирующим основаниям

Координаты кодирующих участков получили из версионных транскриптов RefSeq для hg19. Пересекающиеся участки внутри каждого гена объединили. В знаменатель включили все выбранные основания, в том числе позиции с нулевой глубиной.

Учитывали первичные выравнивания правильно сопоставленных пар с известной оценкой качества картирования не ниже 30 и оценкой качества основания не ниже 30. Исключили дубликаты и записи с ошибкой контроля качества. Совпадающие основания в перекрытии одной пары засчитывали один раз. Противоречащие наблюдения одной пары в данной позиции исключали. Для сравнения глубины в двух наборах проверяли достижение порога в одной и той же координате.

Результаты двух реализаций подсчёта сверили по каждой позиции. Извлечение данных из индекса отдельно повторили в выбранных точках и на границах. На искусственных чтениях проверили обработку пропусков, вставок, наложения концов пары, низкого качества и разных групп чтений.

## Сопоставление со справочником

Для поиска пар записей одного гена сначала требовали точного соответствия сборки, координаты и обеих последовательностей аллеля. Затем группировали подходящие записи по гену в пределах одного набора. Повторный расчёт использовал другое представление входных данных и числовой идентификатор гена. Записи без данных о частоте сохраняли с пропуском.
