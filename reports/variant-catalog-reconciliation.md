# Сверка технической таблицы с исходным VCF

Для каждой записи сохранили фильтр, исходный генотип, глубину и качество. В многоаллельных позициях каждую альтернативу, указанную в генотипе, вынесли в отдельную строку. Число копий и число поддерживающих чтений извлекли по индексу соответствующей альтернативы. Исходный номер позиции и порядок аллелей сохранены.

Число записей с отметкой PASS до разделения сравнили с отдельной сводкой программы DRAGEN. Для сопоставления между файлами использовали сборку, хромосому, позицию и обе последовательности аллелей. Отсутствие точного совпадения оставили отдельным состоянием. Для оценки референсного генотипа проверяли блоки gVCF, глубину и качество на всём интервале.
