# Контроль завершения постобработки

После маркировки дубликатов и перекалибровки проверили сохранность записей выравнивания, флагов, последовательностей, координат и исходных значений качества. Восстановленные значения качества сопоставили по контрольным суммам. Проверены индекс, словарь референса и успешное завершение команд.

В отдельной паре последовательных команд системные часы вернулись назад. Для этой пары порядок выполнения воспроизвели по сохранённым контрольным суммам, последовательности операций, времени закрытия файлов и длительностям, измеренным монотонными часами. Оценка ограничена проверенной парой команд. Для новых, ещё не начатых запусков подготовлен учёт границ каждой команды по монотонным часам с сохранением исходных отметок UTC.
