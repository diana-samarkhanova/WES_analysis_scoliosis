# Перенос контрольных окон между сборками

Из 912 заранее выбранных окон публичной референсной последовательности в другую сборку перенесены 836. Для каждого окна искали центральную последовательность длиной 31 основание на обеих цепях всех последовательностей обеих сборок, включая альтернативные. Для переноса требовали единственного положения центра в каждой сборке и полного совпадения 131 основания вместе с флангами. Отдельно сверили ориентацию, порядок окон и сохранность контрольных групп с разным содержанием гуанина и цитозина.

Эта проверка относится к референсным последовательностям. Покрытие в конкретной библиотеке измеряют отдельно.

## Проверка сопоставления записей

Для точного поиска в справочнике ClinVar учитывали сборку, позицию и обе последовательности аллелей. Категорию клинической значимости, наличие критериев оценки и конфликты между заключениями проверяли до сопоставления. Для контроля повторили поиск в обратном порядке. Отдельно убедились, что этим способом находятся точные совпадения записей при других генотипах.

При проверке коротких вставок и делеций учитывали возможность записать одно изменение в нескольких соседних позициях. Покрытие вокруг изменения оценивали по всей последовательности интервала. Пропуски и перекрывающиеся записи сохраняли как неопределённые.
