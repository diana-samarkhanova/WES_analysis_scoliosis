# Проверка границ интронов и контекста выравнивания

Из версионированных моделей RefSeq для GRCh37 извлекли первые и последние два основания интрона с учётом направления транскрипции. Для отобранных позиций проверили оба конца интрона и каноническую пару GT–AG по референсу. При сверке с архивным gVCF хранили раздельно явный вызов, надёжный референсный блок и недостаток данных. Для фазирования отличали вывод из генотипов от наблюдения на одном фрагменте и проверяли наличие метки фазового блока.

Для подбора технических контролей сравнили участки длиной 131 основание между hg19 и GRCh38. Обе полные референсные последовательности проверили по SHA-256. Поиск включал обе цепи и дополнительные контиги. Все совпадения короткого поискового фрагмента проверяли по полной длине. Отдельно оценивали центральное основание и совпадение ближайших флангов в архивных чтениях. Однозначное совпадение между референсами не устанавливает генотип в новом выравнивании.
