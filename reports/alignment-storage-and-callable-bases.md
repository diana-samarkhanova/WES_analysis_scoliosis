# Объём выравниваний и проверка доступных для анализа позиций

Для расчёта дискового пространства свели отчёты FastQC для 232 входных файлов. У обеих сторон каждой из 116 пар файлов совпало число прочтений. Объём индексированных выравниваний взяли из файлов, для которых успешно завершились проверки. Нижнюю и верхнюю оценки рассчитали раздельно по наблюдаемым значениям байтов на пару прочтений.

При сохранении всех трёх стадий выравнивания расчётный дополнительный объём составляет 499–560 ГБ. При сохранении только итоговых перекалиброванных выравниваний с индексами расчёт составляет 251–254 ГБ. Обе оценки исключают файлы вариантов, базы аннотации и резервные копии. Один пилот охватывал только часть образца и использовался для оценки размера. Свободное место основной и виртуальной файловых систем проверялось раздельно.

Для проверки небольших вариантов положительные записи сравнивали с блоками референсных генотипов. В выбранном кодирующем транскрипте отдельно считали кодирующие основания и по две ближайшие интронные позиции на каждом конце интрона. Для строгой оценки референсного генотипа требовали однозначный блок, качество генотипа не ниже 30, глубину и минимальную глубину блока не ниже 20. Позиции без записи и позиции с недостаточным качеством учитывались отдельно.
