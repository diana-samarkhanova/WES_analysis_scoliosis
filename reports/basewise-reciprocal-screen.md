# Проверка возможных замен по каждой позиции

Для каждой позиции заданного участка рассмотрели три альтернативы референсной букве. Сравнение выполнили в обоих направлениях. Позиции выбирали по справочной последовательности, поэтому список записей, ранее выданных программой поиска вариантов, не ограничивал проверку.

На первом шаге определяли максимально возможное число подходящих фрагментов. При этом сохраняли даже противоречащие наблюдения двух концов одной пары. Если верхняя граница достигала заранее заданного минимума, фрагменты в этой позиции извлекали заново и применяли полные правила качества. Независимый пересчёт проверил перечень сравнений и решения на границах фильтров.

На искусственном примере восемь изменённых фрагментов из сорока в первом наборе и ноль из сорока во втором прошли фильтр. При смене направления или уменьшении числа таких фрагментов до четырёх пример фильтр не прошёл. Тест проверяет работу правила на заданных входных данных. Для оценки чувствительности на реальном материале нужна отдельная валидация.
