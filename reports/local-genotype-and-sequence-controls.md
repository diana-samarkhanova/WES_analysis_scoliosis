# Контроль локальных генотипов и последовательности чтений

При чтении архивного gVCF через индекс сравнили результаты двух запросов, охватывающих одну позицию, с разными границами окна. Для однонуклеотидных замен референсный генотип принимали из покрывающего блока с достаточной минимальной глубиной и качеством. Для короткой вставки такие блоки исключали из знаменателя. Число пригодных генотипов считали отдельно в каждой позиции.

При проверке близких изменений сравнили четыре возможные последовательности на фрагментах, перекрывающих весь участок. Подсчёт повторили с флангами длиной 12, 21 и 31 нуклеотид с каждой стороны. Перекрывающиеся концы одной пары учитывали один раз. Проверили ориентации и число различных границ фрагментов. Совместный эффект на кодирующую последовательность рассчитывали по конкретной версии транскрипта.
