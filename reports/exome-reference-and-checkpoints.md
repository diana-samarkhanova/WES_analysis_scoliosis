# Расширение проверки на кодирующую часть экзома

По аннотации RefSeq на сборке GRCh37 подготовлен набор из 34 359 754 кодирующих позиций основных ядерных хромосом. Он охватывает 19 328 обозначений генов. Пересечения экзонов разных транскриптов учитываются один раз. Координаты X и Y подсчитаны раздельно. Модели с неполной или несогласованной кодирующей последовательностью учтены отдельно. Такой знаменатель описывает аннотацию генома, а фактическое покрытие измеряется по чтениям.

Координаты независимо восстановлены из аннотации. Два способа чтения референсной последовательности дали одинаковый результат для всех выбранных позиций. Среди них каждая референсная буква определена. Дополнительные интервалы обрабатываются отдельно от основной кодирующей области.

Для проверки глубины перекрывающиеся концы пары группируются по идентификатору фрагмента и группе чтений. При поиске различий сначала вычисляются верхние границы числа поддерживающих чтений. Отобранные замены проходят проверку по фрагментам и дополнительный подсчёт с поправкой на перекрытие. Сбой в одном участке допускает продолжение с проверенного результата предыдущего. В контрольном наборе искусственных чтений проверены различия в двух направлениях, ошибки ориентации, недостаточная глубина и противоречащие друг другу основания пары.
