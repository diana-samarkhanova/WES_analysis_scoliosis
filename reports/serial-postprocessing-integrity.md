# Проверка последовательной обработки выравниваний

Для очередного завершённого выравнивания сверены 25 успешно завершившихся команд, их журналы, число записей, сохранение исходных качеств оснований и результат перекалибровки. После проверки число образцов с подтверждённой постобработкой достигло трёх.

При расхождении между соседними отметками системного времени порядок выполнения проверили отдельно. Использовали исходный последовательный вызов, монотонные длительности, журнал выполнения и порядок сохранения файлов. Исключение привязано к контрольным суммам этой попытки. Для следующей попытки действует исходная проверка хронологии.

Перед использованием готового выравнивания предусмотрена повторная сверка контрольных сумм файла и его индекса. Продолжение использует ту же блокировку, что и исходная последовательная обработка.
