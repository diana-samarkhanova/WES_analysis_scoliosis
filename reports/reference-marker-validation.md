# Проверка референса и панели маркеров hg19

3 ноября 2026 года. Проверены координаты публичной панели peddy GRCh37 для работы с архивным анализом на UCSC hg19.

| Проверка | Результат |
| --- | --- |
| Последовательности FASTA, у которых контрольная сумма M5 совпала с опубликованной таблицей Broad для hg19 | 93 из 93 |
| Аутосомные маркеры, у которых референсное основание в позиции панели совпало с FASTA | 23 770 из 23 770 |
| Проверенные маркеры внутри интервалов архивного аналитического BED | 20 098 |

При переходе от координаты маркера к BED использован однонуклеотидный интервал с нулевым началом и исключённой правой границей. Целевые интервалы учитывались без расширения. Эти проверки устанавливают совместимость координат и референсных оснований. Фактическую глубину в позиции определяют отдельно.

Источники для воспроизведения проверки — [версия публичной панели peddy](https://github.com/brentp/peddy/blob/1d340cd3e87623c8c58b4a82b18f33ba532101aa/peddy/GRCH37.sites) и [таблица последовательностей Broad](https://github.com/broadinstitute/gatk/blob/0cde69eed30339f5978cbb1ac6e5cf3662f9e1f8/docs/funcotator/forum_info/forum_post_human_reference_discrepancies.md).
