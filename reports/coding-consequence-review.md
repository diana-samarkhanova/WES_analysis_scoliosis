# Проверка последствий для кодирующей последовательности

Для архивных данных GRCh37 восстановили кодирующую последовательность версионированных транскриптов RefSeq с учётом цепи и порядка экзонов. Для поиска преждевременных стоп-кодонов и сдвигов рамки использовали модели с полным началом и концом трансляции. Раздельно учитывали короткие вставки и делеции, близкие изменения и неопределённую фазу. Изменение рамки в одном транскрипте само по себе не устанавливает потерю функции белка.

При сверке с ClinVar проверяли точное совпадение сборки, позиции и обоих аллелей. Другие однонуклеотидные замены в том же кодоне переводили отдельно для каждого подходящего транскрипта. Независимая проверка повторила выборку по координатам и пересчёт аминокислотных замен.
