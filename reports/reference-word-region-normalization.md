# Нормирование числа совпадений с референсом

Точный подсчёт коротких уникальных последовательностей в исходных парных чтениях проверили независимо от выравнивания. Для основной оценки требовалось качество Q30 на всём участке. Два чтения одной пары с совпадением учитывали один раз. Контрольные суммы и идентичность файлов связывали с предыдущей проверкой, а текущий проход проверял порядок пар, целостность сжатого потока и достижение конца обоих файлов.

Для сравнения использовали одинаковый набор пригодных участков у всех сопоставляемых библиотек. Масштаб определяли по контрольным участкам отдельно для групп с близкой долей G и C. Второй набор контрольных участков оставляли вне расчёта масштаба и использовали для проверки нормирования. Расчёт медиан повторили по сохранённым счётчикам.
