# Проверка полноты данных по кодирующей области

Для кодирующих моделей RefSeq объединили перекрывающиеся основания, сохранив отдельно первые и последние два интронных основания каждого стыка. При сверке обычного VCF и gVCF учитывали явные записи, в том числе отфильтрованные, и границы референсных блоков. Для каждой позиции различали уверенный генотип, низкое качество и отсутствие записи.

Для позиций без уверенного генотипа в gVCF отдельно посчитали фрагменты исходного выравнивания. Перекрывающиеся концы одной пары учитывали вместе. Глубину после фильтров и число фрагментов с каждым основанием сохранили раздельно. Это позволило отличить пробел в файле генотипов от пробела в покрытии.

При оценке аминокислотной замены проверили исходный кодон по референсу и исключили из одиночной интерпретации кодоны с другими перекрывающимися вызовами. Для сверки с ClinVar использовали точное совпадение сборки, координаты и последовательностей обоих аллелей.
