# Итоговая проверка интервального расчёта и gVCF

Независимая проверка охватила все 1 297 запланированных интервалов. Для каждого интервала заново прочитали массив глубин, проверили его длину и контрольную сумму. Затем восстановили распределение глубины и сравнили итоговые числа с журналом завершения. По координатам проверили, что интервалы в сумме покрывают запланированную область без двойного счёта.

Для оценки влияния глубины на отбор использовали биномиальную модель с порогами числа и доли чтений. Средние рассчитали по фактическому распределению глубины. Другая реализация воспроизвела расчёт по всем представленным значениям глубины. Такая модель описывает случайную выборку фрагментов. Для измерения чувствительности также нужны материалы с известным составом и проверка ошибок выравнивания и чтения.

При проверке gVCF сравнили число и последовательность декодированных записей при сплошном чтении и чтении через индекс. Предупреждения строгой проверки воспроизвели по координатам и типам перекрывающихся записей. До отдельной проверки спорных участков использование такого файла для совместного генотипирования приостановлено.
