# Глубина чтения по архивным отчётам hg19

[Открыть таблицу глубины (CSV)](legacy-hg19-depth.csv)

Сводка от 3 ноября 2026 года. Глубина измерена в архивном анализе DRAGEN по целевым интервалам на референсе hg19. Таблица охватывает 32 образца. Для 31 архивная гистограмма доступна, для одного соответствующего отчёта в проверенной папке нет. Отдельный повторный анализ проводится на hg38.

| Столбец | Значение |
| --- | --- |
| `row_id` | Случайно присвоенный технический код строки этой таблицы. |
| `archived_report` | Доступность архивной гистограммы. При значении `unavailable` поля измерений пусты. |
| `mean_depth_x` | Среднее число прочтений на основание в целевой области по отчёту DRAGEN. |
| `pct_bases_0x` | Процент учтённых оснований с нулевой глубиной. |
| `pct_bases_ge30x`, `pct_bases_ge50x`, `pct_bases_ge100x` | Процент учтённых оснований с глубиной не ниже 30×, 50× и 100× соответственно. |

Знаменатель каждой доли составляет 35 141 032 основания, вошедших в гистограмму. Полная длина 202 566 неперекрывающихся интервалов исторического BED составляет 35 241 032 основания. Причина расхождения в 100 000 оснований по этим сводкам не установлена. Проценты округлены до двух знаков.

Координаты отчётов сверены с историческим BED. Средняя глубина проверена по сумме выровненных оснований, пороговые доли рассчитаны из гистограмм. По этим сводным числам нельзя определить глубину в конкретной позиции или точный набор лабораторного захвата.
