# Сопоставление записей между наборами

Для точного совпадения малой замены использовали сборку, хромосому, позицию и оба аллеля. Для совпадения по гену отдельно сопоставляли символы генов из одного выпуска аннотации. Региональное совпадение проверяли по пересечению измеренных интервалов с кодирующей последовательностью.

Уверенный референсный генотип, положительный вызов и позицию без достаточных данных сохраняли раздельно. Частые записи в описательном каталоге отделили от записей с дополнительной проверкой генотипов. Для проверочных позиций данные перечитали последовательно из исходных файлов и сравнили с индексированным чтением. Контроль с подстановкой другого альтернативного аллеля проверял, что несовпадение аллеля сохраняется как неопределённый результат.

Парные пересечения по генам и точным заменам пересчитали независимо. После упаковки таблиц проверили контрольные суммы, количество строк и соответствие полей исходным записям.
