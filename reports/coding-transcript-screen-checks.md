# Проверка совпадающих вызовов в архивных данных

Для поиска общих кодирующих изменений сопоставляли хромосому, позицию, обе последовательности аллелей и число копий альтернативного аллеля в качественных вызовах. В отбор включали аутосомные однонуклеотидные замены и простые короткие вставки и делеции. Для пар требовали две разные позиции в одной и той же версии кодирующего транскрипта. Отдельно учитывали, позволяют ли данные определить расположение изменений на разных копиях хромосомы.

Для отобранных позиций повторили расчёт последствия по референсной последовательности с учётом направления транскрипции. При оценке отсутствующего вызова различали отсутствие записи и покрывающий позицию референсный блок достаточного качества. Для коротких вставок и делеций одного референсного блока в начальной позиции недостаточно, чтобы исключить другую запись того же изменения.
