# Проверка объединения выравниваний из нескольких файловых пар

На синтетических BAM-файлах проверили объединение координатно отсортированных выравниваний одного образца. Для каждой входной пары файлов задан отдельный технический идентификатор группы прочтений. Проверка требует согласованных имён и длин референсных последовательностей, порядка сортировки и принадлежности групп одному образцу.

После объединения для каждой группы сравнивают число записей и отсортированные списки контрольных сумм отдельных записей с учётом повторов. Сверяются флаги, координаты, CIGAR, последовательности, качества, типы и значения дополнительных полей. Изменение порядка дополнительных полей допустимо. Подмена одной записи другой с тем же общим числом записей проверку не проходит.

Испытание выполнено только на синтетических данных. Для допуска к исследовательской обработке ещё нужны проверка индекса готового BAM, оценка ресурсов на пилоте и проверка последующей обработки с несколькими группами прочтений.
