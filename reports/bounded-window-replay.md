# Проверка воспроизводимости обработки gVCF в четырёх окнах

Для каждого из четырёх заранее выбранных окон обработку gVCF повторили с двумя размерами флангов. В восьми полученных VCF проверили формат и чтение через индекс, затем сопоставили записи в общей центральной части каждой пары окон. Предупреждения исходного gVCF сверили отдельно. Вывод о воспроизводимости ограничен проверенными окнами.
