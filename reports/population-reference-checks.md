# Локальная проверка популяционных частот

Для архивной сборки GRCh37 использовали gnomAD exomes v2.1.1. Полный VCF одной хромосомы сверили с размером и контрольной суммой поставщика и прочитали до конца. Для общей таблицы UCSC проверили полноту и структуру файла bigBed, сжатые блоки, координаты и операции чтения через индекс. Поиск по индивидуальным наблюдениям выполнялся локально.

Сопоставление требовало совпадения сборки, хромосомы, позиции и обеих последовательностей аллелей. Для точных совпадений отдельно учитывали фильтр качества, число копий аллеля и число оценённых копий. Одинаковые записи в двух представлениях одного выпуска относятся к одной популяционной выборке. Если записи нет, частота остаётся неизвестной.
