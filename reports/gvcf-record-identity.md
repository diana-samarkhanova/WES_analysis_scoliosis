# Сверка записей при перекрытии интервалов gVCF

Для части сохранённых предупреждений удалось воспроизвести исходное представление шести полей записи и сверить его по SHA-256. Проверяли обе строки каждой сравниваемой пары. При подсчёте различали уникальные строки и их повторные появления в разных парах.

Для следующего чтения полных записей подготовили отдельную проверку. Она сопоставляет строки из последовательного прохода и запроса по индексу, проверяет заголовок, координаты и порядок. Поля, отсутствующие в сокращённом представлении, можно получить только из полных исходных строк. На искусственных полях качества прошли 11 тестов формата и обработки несоответствий.
