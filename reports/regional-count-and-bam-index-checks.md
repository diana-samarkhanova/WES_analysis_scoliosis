# Проверка региональных счётчиков, индексов и дубликатов

Для отбора последовательных интервалов со сходным изменением числа выравниваний правила задали до расчёта. При нормировке исключали проверяемую хромосому и маскированные интервалы. Неинформативный интервал прерывал серию. Независимая реализация воспроизвела координаты, исходные счётчики и медианные отношения. Метод позволяет выбрать участки для последующего исследования. Он не определяет абсолютное число копий.

На синтетических BAM отдельно проверили индекс BAI. Полное последовательное чтение сравнили с чтением по явно указанному индексу. Проверялись все записи каждой группы, в том числе записи без координаты. Контроли включали индекс другого файла и устаревший индекс с совпадающими количествами записей. Все 11 тестов прошли.

В пяти синтетических сценариях HTSJDK изменяли сведения о библиотеке и группе прочтений. При одинаковой геометрии пары результат маркировки дубликатов между группами зависел от поля библиотеки. Присвоение отдельных групп файлам само по себе не устанавливает, сколько физических библиотек было приготовлено.
