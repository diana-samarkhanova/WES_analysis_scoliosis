# Подсчёт фрагментов в перенесённых окнах GRCh38

Для 836 заранее перенесённых окон GRCh38 пересчитали фрагменты по выравниваниям. В каждом окне подсчитали число фрагментов с качеством картирования не ниже 30. При более строгой фильтрации с порогом 40 подсчитали как число фрагментов, так и число различных положений парных чтений. Для нормализации использовали контрольные окна с сопоставимым содержанием гуанина и цитозина. Итоговые показатели независимо пересчитали по сохранённым таблицам.

Сравнение расширили на дополнительные выравнивания. Для всех попарных сравнений с общим набором окон повторно проверили коэффициенты нормализации, медианы и квартили. Независимый пересчёт воспроизвёл все проверенные значения.
